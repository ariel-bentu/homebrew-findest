# Homebrew tap for Findest

[Findest](https://github.com/ariel-bentu/findest) is a fast, keyboard-friendly file browser for macOS.

```sh
brew install ariel-bentu/findest/findest
findest   # installs Findest.app and opens it
```

The formula builds from source on your Mac, so you won't see Gatekeeper warnings. The first install takes a few minutes while Rust compiles it.
